## Running Locally

Clone the repository and install the dependencies:

```bash
git clone <your-repository-url>
cd <your-repository-name>
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

For production:

```bash
npm run build
npm start
```

To check the project with ESLint:

```bash
npm run lint
```

## Project Structure

```text
src/
├── app/              # App Router pages and API routes
├── components/       # Reusable UI components
├── data/             # Portfolio content and data
└── lib/              # Utility functions and helpers

public/
└── images/           # Portfolio images and media
```

### Updating Content

Most portfolio content is separated into data files so it can be updated without changing the main UI components.

| Content | Location |
| --- | --- |
| Name, bio & social links | `src/data/site.ts` |
| Brands & reels | `src/data/roster.ts` |
| Services | `src/data/services.ts` |
| Pricing | `src/data/pricing.ts` |
| Experience | `src/data/experience.ts` |
| Images | `public/images/` |
